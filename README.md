# Анализатор успеваемости студентов

## 1. Описание проекта

**Анализатор успеваемости студентов** — консольное приложение на Python для обработки данных об оценках студентов из CSV-файла.

Программа проверяет входные данные, рассчитывает основные статистические показатели, выводит результаты в виде таблицы и сохраняет отчёт в формате JSON.

Проект разработан в рамках лабораторной работы № 6 «Сборка и управление зависимостями в Python».

## 2. Возможности программы

- Чтение данных студентов из CSV-файла.
- Проверка наличия обязательных столбцов `student`, `group`, `score`.
- Проверка корректности оценок: целые числа от 0 до 100.
- Подсчёт количества студентов.
- Расчёт среднего, минимального и максимального баллов.
- Расчёт среднего балла для каждой группы.
- Вывод результатов в форматированной таблице с помощью библиотеки Rich.
- Сохранение статистики в JSON-файл.
- Обработка ошибок входных данных.

## 4. Требования

- Python 3.
- Библиотека `rich`.

## 5. Установка

Откройте терминал в корневой папке проекта.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

Если файл `requirements.txt` ещё не содержит библиотеку Rich, установите её отдельно:

```powershell
python -m pip install rich
```

## 6. Формат входных данных

CSV-файл должен содержать три обязательных столбца: `student`, `group`, `score`.

Пример:

```csv
student,group,score
Иванов,ИС-21,85
Петров,ИС-21,70
Сидорова,ИС-22,95
Смирнов,ИС-22,80
Кузнецова,ИС-21,90
```

Оценка должна быть целым числом от 0 до 100. Файл сохраняется в кодировке UTF-8.

## 7. Запуск программы

Для анализа примера данных выполните:

```powershell
python main.py data/students.csv --output report.json
```

Где:
- `data/students.csv` — путь к входному CSV-файлу;
- `--output report.json` — путь к выходному JSON-файлу.

Программа выводит таблицу со статистикой в терминал и сохраняет результаты в `report.json`.

## 8. Результаты работы

Для предоставленного примера ожидаются следующие показатели:

- Количество студентов: 5.
- Средний балл: 84.00.
- Минимальный балл: 70.
- Максимальный балл: 95.
- Средний балл группы ИС-21: 81.67.
- Средний балл группы ИС-22: 87.50.

## 9. Проверка ошибок

Программа должна сообщать об ошибках, если:
- входной файл не существует;
- отсутствуют обязательные столбцы;
- одно из полей пустое;
- оценка не является целым числом;
- оценка находится вне диапазона от 0 до 100.

При обнаружении некорректных данных отчёт не должен создаваться.
